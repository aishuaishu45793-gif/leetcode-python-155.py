# 🐍 Python Practice Programs

Welcome to my Python practice repository! 🎉

This repository contains five Python programs designed to improve my programming knowledge, logical thinking, and problem-solving skills. These programs cover essential Python concepts such as lists, strings, loops, conditional statements, mathematical operations, and built-in functions.

## 📌 About This Project

The main objective of this project is to practice Python programming through simple, practical examples. Each program solves a specific problem and helps build a strong foundation in Python.

## 📂 Programs Included

| Program Name                            | Description                                                                                       | Concepts Used                           |
| --------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Find the Smallest Number in a List      | Finds the smallest number from a list of integers.                                                | Lists, `min()`, user input              |
| Count Vowels in a String                | Counts the vowels (a, e, i, o, u) in a string.                                                    | Strings, loops, conditional statements  |
| Calculate the Sum of Numbers in a List  | Calculates the sum of all numbers entered by the user.                                            | Lists, loops, arithmetic operations     |
| Armstrong Number Checker                | Checks whether a number equals the sum of its digits raised to the power of the number of digits. | Loops, strings, mathematical operations |
| Find the Second Largest Distinct Number | Finds the second-largest distinct number in a list.                                               | Lists, sets, sorting                    |

## 🚀 How to Run the Programs

### Step 1: Install Python

Download and install Python if it is not already installed on your computer.

### Step 2: Install Visual Studio Code

Install Visual Studio Code to write, edit, and execute Python programs.

### Step 3: Download the Project

Clone the repository containing the program you want to run:

```bash
git clone <repository-url>
```

Replace `<repository-url>` with your repository URL.

Alternatively, open an individual GitHub repository and download its Python file.

### Step 4: Open the Project

Open the downloaded folder in Visual Studio Code.

### Step 5: Run a Python Program

Open the VS Code terminal and run the appropriate command using your Python filename.

For example:

```bash
python filename.py
```

Replace `filename.py` with the name of your Python file.
